# Сверка КУДиР и ОФД — v1.0.0

Первый публичный выпуск программы для локальной сверки Excel-выгрузок КУДиР и ОФД на Windows.

## Возможности

- Автоматическая сверка поддерживаемых квартальных листов КУДиР и выгрузки ОФД.
- Ручной выбор листов, столбцов и строк для других таблиц.
- Сравнение безналичных по датам продаж с учётом более позднего зачисления в КУДиР.
- Сверка наличных по месяцам и проверка общих сумм.
- HTML-отчёт с разбором каждой разницы, точными ячейками и пояснениями.
- Выгрузка подробностей в CSV для проверки в Excel.
- Отдельное отображение расходных операций ОФД и прочих поступлений.

## Установка и запуск

1. Скачайте **kudir-ofd-1.0.0.zip** из файлов этого выпуска.
2. Нажмите на архив правой кнопкой мыши → **Извлечь всё**.
3. Откройте извлечённую папку и запустите **Запустить.cmd**.
4. Выберите два файла. Для поддерживаемого формата нажмите **Автосверка всех кварталов**.

Подробная инструкция находится в файле **Инструкция.html** внутри архива.

## Требования и ограничения

Нужны **Windows 10/11, Windows PowerShell 5.1 и установленный настольный Microsoft Excel**. Поддерживаются `.xlsx` и `.xls` без пароля. Python и дополнительные библиотеки не требуются.

Программа работает локально, без ИИ и интернет-сервиса для расчётов. Исходные файлы открываются только для чтения.

Автосверка рассчитана на формат, описанный в README. Подсказки помогают найти причину расхождения, но не являются подтверждёнными исправлениями. Программа не меняет записи учёта. Для наличных, внесённых общей суммой за период, конкретный день пропуска не определяется.

## Проверки

Пройдены локальные тесты расчётов и подсказок на вымышленных данных. В комплект не включены реальные бухгалтерские таблицы, отчёты и история разработки с такими данными.

## Лицензия и файлы выпуска

**Свободное ПО под лицензией MIT.** Полный текст лицензии включён в архив.

- `kudir-ofd-1.0.0.zip` — готовый комплект для запуска.
- `kudir-ofd-1.0.0.sha256` — контрольная сумма SHA-256 архива.

Контрольная сумма позволяет проверить целостность скачанного файла; это не цифровая подпись издателя.
