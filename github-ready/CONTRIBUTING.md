# Участие в проекте

Сообщайте о проблеме через Issues: версия Windows и Excel, ручной или автоматический режим, ожидаемый результат и фактический результат. Не публикуйте реальные выгрузки, ИНН, банковские реквизиты, пути с именами пользователей или назначения платежей.

Для нового формата приведите заголовки столбцов и минимальный пример на полностью вымышленных данных. Для ошибки расчёта добавьте регрессионный тест. Не подменяйте неизвестные значения нулями и не маркируйте предполагаемую ошибку как доказанную.

Перед Pull Request выполните `tests.ps1` и `tests-auto.ps1`. При изменении чтения Excel выполните также `test-excel.ps1` на машине с настольным Excel. Файлы PowerShell с русским текстом сохраняйте в UTF-8 с BOM для Windows PowerShell 5.1.

Вклад в код и документацию предоставляется на условиях лицензии MIT проекта.
